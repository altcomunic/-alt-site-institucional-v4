# ALT Site Institucional V4

Site institucional premium da ALT Comunicação, desenvolvido em React + Vite com foco em design modular, UX, SEO estrutural e conversão.

## Stack

- React
- Vite
- Framer Motion
- CSS customizado
- Lucide React

## Estrutura principal

- Hero
- Manifesto ALT
- Sistema ALT
- Método
- Cases
- Resultados
- Insights
- Parceiros
- Diagnóstico
- Footer

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Publicação na Vercel

Configuração recomendada:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## SEO

Inclui:

- Title e meta description
- Canonical
- Open Graph
- Twitter Card
- JSON-LD Schema.org
- Sitemap
- Robots
- Headers de segurança via `vercel.json`
